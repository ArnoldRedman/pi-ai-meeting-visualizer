## 8 个厂家模型的娘化 chibi，和一间会让它们摸鱼的会议室

我做了 8 个 AI 厂家的 chibi 娘化角色——GPT、Claude、Gemini、Grok、DeepSeek、Kimi、GLM、Qwen 各一个，全是程序化生成的方块小人。为了让它们有事干，又给它们搭了间 3D 会议室：几个模型一起开会时，它们就坐在里面工作、交卷、溜达。**两个仓库都是我写的，工具链全开源。**

![8 个厂家角色：上排 GPT / Claude / Gemini / Grok，下排 DeepSeek / Kimi / GLM / Qwen](https://raw.githubusercontent.com/ArnoldRedman/pi-ai-meeting-visualizer/main/assets/screenshots/character-lineup.png)

八个角色，每个都塞了自家的物件：

- **GPT**：白龙娘，裙子正面是 OpenAI 标志贴花
- **Claude**：橙发大小姐，头花、蝴蝶结、流苏都是几何体
- **Gemini**：紫双马尾，星星发饰、紫裙白围裙
- **Grok**：金发吸血鬼贵族，右手提一把比自己还高的 X 战斧
- **DeepSeek**：蓝鲸女仆，围裙上是官网鲸鱼标志
- **Kimi**：银发月光音乐少女，头饰是新月加一个 K
- **GLM**：黑发女仆档案管理员，徽章是 Z，右手夹着一本 "GLM Model" 手册
- **Qwen**：蓝发汉服少女，标志菱形、蝴蝶结、流苏，左手提袋

### 这些角色可以直接拿走用

**8 个模型单独一个仓库：[pi-meeting-chibis](https://github.com/ArnoldRedman/pi-meeting-chibis)**。每个是一个自带骨架和 32 个动作的 GLB（坐、走、搬东西、点头摇头都有），面数几千，单个 0.5–1 MB、贴图内嵌，丢进 Three.js 或 Blender 就能用，不必连着会议一起用。

做法也说清楚：**没有一个多边形是手工摆的**，几何、配色、贴花、徽章全由 Blender Python 脚本生成——一个共用的几何库加一份"这个角色长什么样"的设计脚本，跑一条命令重建模型，再跑一条命令出九张四视角预览图。骨架和动作复用 Kenney Mini Characters（CC0）的 7 根骨头，无肘无膝，所以动作这块是白拿的。想加一个新厂家角色，本质上是写一份脚本。

### 有了人，就让它们真的去上班

上面那间会议室本来是给我自己用的：我平时用几个模型同时回答同一个问题、匿名互相质询、再投票定案，过程全在终端里是文字，看得人犯困。现在它能被看见——同一场会议，之前是"等八分钟、拿到四段结论"，现在中间那八分钟有形状：

- 各自走到座位坐下开工；
- 干活的留在电脑前，气泡写它公开出来的进度；
- **提前交卷的会离开桌子去溜达**：看窗外、翻书柜、浇绿植、窝沙发上等人；
- 全员完成后回座，一起转向墙上的大屏幕，上面写这一轮到哪了、最终结论是什么；
- 点某个人，镜头拉近，看它的公开档案：职责、立场变化、按轮次记录的结论。

![一个人还在干活，另外三个已经交卷离桌去溜达了](https://raw.githubusercontent.com/ArnoldRedman/pi-ai-meeting-visualizer/main/assets/screenshots/mixed-state.png)

这张是页面里「开始模拟会议」跑出来的——不调用任何模型，半分钟看完一轮，专门用来先看效果。真开会时节奏差不多，只是"谁先答完谁先离桌"由真实耗时决定。

![点开一个席位：公开档案、立场变化和本轮结论](https://raw.githubusercontent.com/ArnoldRedman/pi-ai-meeting-visualizer/main/assets/screenshots/seat-focus.png)

### 想自己跑一遍

需要 Node 22+ 和一个 Pi（跑在终端里的 coding agent）：

```sh
pi install git:github.com/ArnoldRedman/pi-ai-meeting-visualizer
# 装完重开一个 Pi 会话（或 /reload）让扩展生效，然后：
# /meeting open
```

`/meeting open` 起本地服务并打开页面，点「开始模拟会议」就能看。真拿它开会的话再装 [pi-ai-meeting](https://github.com/ArnoldRedman/pi-ai-meeting)：开会那一刻房间会自己出现，Pi 里会给你一条门牌链接。

几个实话：服务只绑 `127.0.0.1`，数据只在内存，Pi 一退就停；它**只接收会议脚本愿意公开的事件**（进度、立场），模型内部怎么推理的它看不到——所以你会看到"它改口了"，看不到"它为什么改口"。小毛病也有：Grok 的斧子、Qwen 的提袋是刚性绑在单根手臂骨上的，手臂往前摆时会跟着歪；没有表情骨骼，情绪只能靠动作。
